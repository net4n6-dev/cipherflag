# Security Policy

## Supported versions

Security fixes are made for the latest 2.x release of CipherFlag CE.
Please upgrade to it before reporting, or confirm the issue is present
in it.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public GitHub
issue, pull request or discussion for them.

Email **info@cipherflag.com** with:

- a description of the issue and its impact;
- the CipherFlag version (`cipherflag version`) and how it is deployed;
- steps to reproduce, or a proof of concept;
- any logs, requests or files that help (remove real secrets and
  certificates you do not want to share);
- how you would like to be credited, if at all.

We will acknowledge your report. Please give us a reasonable chance to
investigate and release a fix before you disclose the issue publicly.
